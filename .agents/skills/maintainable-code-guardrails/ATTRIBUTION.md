# Attribution

`maintainable-code-guardrails` is an original, condensed Codex skill informed
by the structure and cross-language principles of Wondel.ai’s MIT-licensed
`clean-code` skill:

- Source: https://github.com/wondelai/skills/tree/main/clean-code
- Evaluated revision: `dd37ee506ff558e939b3d421557987cced49b866`
- Upstream skill version at evaluation: `1.4.0`

This adaptation narrows enforcement to code touched by the current task,
replaces universal numerical thresholds with context-dependent risk signals,
adds directory-organization and project-rules integration, and removes the
Boy Scout Rule as authorization for unrelated refactoring.
