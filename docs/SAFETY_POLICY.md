# 运行与数据安全边界

本文件约束实际外部效果，不新增业务能力。Git 权限见 [根规则](../AGENTS.md#git-硬约束)，任务失败处理见 [工作流程](WORKFLOWS.md#failure-containment-contract失败隔离)。授权以当前任务及已明确的范围为准；已有授权不重复询问，阅读代码或保存连接资料不等于运行授权。

## 授权与环境

- 下载、Docker 操作、目标框架源码注册、模型实现适配、服务启停和评测须匹配本次授权的主机、载体、路径、设备和操作。客户完整流程可按公开契约准备共用 EvalScope，以及任务专属 AISBench/资产 SDK 环境；不自动安装驱动、CANN、Docker 或切换工具。旧内部请求的环境前提保持原样。
- 客户 EvalScope 每次准备调用原版安装脚本，可显式传 version/upgrade；默认共享 /data/evalscope-venv，不自动选择其他环境。验证 venv 与技能、输入、资产、证据不重叠；失败保留日志和部分安装，不重试或清理。安装与评测按串行约定运行，本次不提供锁。实际 Python 或 EvalScope 版本变化要求新 run-id，旧精度结果不能复用；详见[安装契约](../skills/vllm-model-migration/references/evalscope-installation.md)。
- 本地控制入口与目标 Linux/NPU 环境分开验证。macOS 静态检查不证明 Linux `/proc`、Docker、CANN、NPU 或原生评测可用。
- 操作前重新核对实际版本、镜像、资产、设备占用、端口和资源归属。历史模型名、TP、设备编号或服务器状态不作默认值。
- 参考代码和外部配置先确认来源、版本、许可及允许的执行范围；不能为读取文档执行配置脚本、远程代码或加载权重。
- 既有模型来源切换等特定流程按对应 Skill 契约及本次授权处理，不将其泛化为自动换模型、工具或环境；不新增重试或自动修复循环。

## 资产与证据保护

模型、数据、镜像归档、请求和证据使用明确的资源外位置；工作根不得覆盖完整技能资源根、来源证据、输入或资产。路径和摘要属于实际执行环境，不把开发机路径直接用于服务器或容器。

保留现有路径规范化、链接越界、解包安全及内容身份检查；不能为了让示例运行而绕过它们。完整资源根与资源枚举/复制规则见 [架构](ARCHITECTURE.md#9-路径与资源契约)；本地路径回归不代替容器、服务器或真实资产验收，未知边界不能以真实资产试错。

新尝试不覆盖旧请求、报告和失败结论。临时文件只处理本次创建且能核对身份的对象；失败保留部分成果，不自动回滚或删除用户资产。共享证据无法保存时停止后续效果，不能报告成功。

客户部署有一项明确例外：task 指定名称的既有容器经观察及删除前复核均为 exited、未运行，且完整 CID/image/StartedAt 与名称一致时，verify-agent 自动按完整 CID 非强制删除并续接重建，无需额外授权，不删除镜像或卷。身份或状态变化时阻塞；其他状态仍需绑定身份的显式授权。此规则不扩展为其他用户资产、borrowed 服务或全局容器清理，细节见[同名容器替换契约](../skills/vllm-model-migration/references/customer-observations.md#同名容器替换)。

模型运行资源复制只包含契约要求的完整业务技能资源；不得夹带仓库 `.git`、维护文档、规则、`.agents/` 开发技能、`.codex/` 质量配置、凭据或运行输出。资源枚举不依赖构建清单或 Git；运行摘要只写入包外证据，不修改静态资源。目录和类型规则不能辨认任意误放文件中的凭据，静态目录必须由维护者保持为可交付资源。

## 进程与服务所有权

`verify-agent` 是模型服务生命周期唯一所有者；总入口和阶段通过其公开 CLI 委托。精度任务只拥有本次评测子进程和记录器，准备任务不启动模型服务。

- borrowed 服务始终保留；总入口从 migration.result 复用的服务也不停止。
- 有精度消费者的服务先保持 keep；顶层显式 stop 在消费者完成后只作用于本次新迁移可证明拥有的服务。独立 verify 的失败清理及 retention 按其契约执行。
- 使用完整 CID/image/StartedAt 或 PID/starttime/进程组及契约要求的 owner 身份；不以名称、端口、主进程退出推断资源已释放，禁止全局 `pkill` 或无归属的容器清理。
- 超时、取消或停止失败后核对实际资源；未确认则交付 unknown/失败，不能声称服务已停止或设备已释放。Docker CLI 退出也不证明 daemon 已停止拉取。

## 凭据保护

不得向新规则、模板、运行请求、argv、日志、报告或记忆复制密码、令牌、私钥及含凭据 URL。凭据只使用已授权环境的配置，错误输出不应回显输入秘密；当前证据可能保留原始 stdout/stderr，不能承诺任意秘密都会自动脱敏。

提交文件和打包技能资源前，应排除私有连接配置。访问服务器前须核对本次授权的目标与操作范围。
